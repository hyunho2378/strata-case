# Strata 케이스 스터디

동해시 공공시설 운영 정보 통합 서비스 Strata의 전시용 케이스 스터디 사이트(제19회 디지털인문예술전공 프로젝트 전시회, 2026. 12. 1.~12. 3.).
크레딧: 2026 한림 G-Lab@동해 AI 활용 지역문제해결 해커톤 출품작

## 실행

```
npm run dev      # http://localhost:5193 (Vite, React 18, GSAP)
npm run build    # vite build --minify false (네이티브 압축기 바인딩 오류 회피)
npm run preview  # 빌드 결과 미리 보기, 포트 5193
```

- 2026. 11. 22. 기준 이 컴퓨터의 127.0.0.1:5193 은 다른 작업(uia-annual-report 의 python 서버)이 쓰고 있어 확인은 `http://[::1]:5193/` 로 함
- `public/app/` 은 Strata 시민 화면(원본 `01. 교과목/01. 서비스 디자인/Strata/prototype/client`)을 `STRATA_BASE=/app/ npx vite build --minify false --outDir <이 폴더>/public/app` 로 다시 빌드한 결과. 원본 dist 는 건드리지 않음
- `/app/` 하위 주소 새로고침은 `vite.config.js` 의 appFallback(개발, 미리 보기)과 `vercel.json` rewrite(배포)가 `app/index.html` 로 보냄
- 깃은 로컬 커밋만. 푸시와 배포는 하지 않음

## 검수 3차(2026. 11. 23.) 반영

### 자동 재생 데모 3곳

| 자리 | 데모 | 재생 내용 |
|---|---|---|
| 시민 흐름 | `DemoCitizen` | 첫 화면에서 한파쉼터와 무더위쉼터 줄이 눌리고 목록이 밀려 들어온 뒤, 동막경로당을 열면 공사 일정과 대신 갈 곳 3곳, 전화 걸기가 차례로 올라옴. 7초 주기로 되돌아감 |
| 담당자 흐름 | `DemoStaff` | 공지 원문에서 기간과 사유, 이용 불가 범위, 대체 안내 문장에 표시가 생기고 읽은 값 여섯 줄이 하나씩 등장. 확인 단추가 눌리면 오른쪽 시민 화면이 운영 중단으로 바뀌고 쉬운 말 안내문이 나옴 |
| 3D 상황판 | `DemoStack` | 대룡빌딩에 겹친 민방위대피와 진료, 약국 층이 위로 갈라지며 이름과 수용 인원이 붙고, 진료 층이 멈춤 상태가 되어 빨강으로 바뀜 |

데모는 코드로 다시 짠 재현 화면이며 글과 수치는 실제 Strata 화면 그대로임. 화면에 들어오면 재생하고 벗어나면 멈춤(IntersectionObserver). 움직임 줄이기를 켠 기기는 마지막 상태로 고정. 직접 눌러 보는 iframe은 "직접 써 보기" 구간에만 둠.

## 확인 못 한 것

- 실제 휴대폰 기기와 휴대폰 앱 안 브라우저에서 열어 보지 않음
- 영상 녹화(webm, mp4) 데모는 이 컴퓨터에 ffmpeg가 없어 만들지 않음. 데모는 코드 재현 화면과 GSAP 재생으로 대신함
- 직접 써 보기 안의 말로 묻기는 서버와 외부 AI 키가 없어 "맞는 시설 없음" 답만 나옴
- 배포 주소에서 `/app/` 새로고침은 배포하지 않아 확인하지 않음
